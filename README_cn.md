# Serial Over Socket (Go 语言版)

一个基于 Go 语言实现的高性能串口转 WebSocket 服务器与客户端系统（Serial-over-WebSocket）。

本项目支持通过**现代化的 Web 网页端**或**强大的 TUI 终端客户端**远程访问和控制多个串口设备。系统具备**中央命令历史同步（SSOT）**、**多串口后台实时并发接收**、**WebDAV 云端自动备份**以及 **Systemd 系统服务开机自启**等诸多高级特性。

## 🔒 安全说明

**本服务端没有任何鉴权。** 能连上它的人无需登录即可列举、打开、关闭串口，向串口写任意字节，并读取全部串口输出。本项目面向**可信局域网**设计：切勿直接暴露到公网；不需要远程访问时用 `sos-server -address 127.0.0.1` 只绑本地回环。详情与漏洞报告方式见 [SECURITY.md](SECURITY.md)。

## 🌟 核心特性

### 1. 服务端 (`sos-server`)
- **单端口统一通信**：所有串口数据流与控制指令统一通过单个 WebSocket 端口通信（默认端口：`2025`）。
- **USB 串口自动发现与热插拔**：自动扫描系统 USB 串口设备，支持实时检测设备插拔事件并全网广播。
- **多串口后台并发实时接收**：优化后的 WebSocket 二进制数据协议，支持多个串口在后台同时接收数据并路由至各自独立终端。
- **中央命令历史 (SSOT)**：服务端作为单一事实来源（Single Source of Truth），所有连接的 Web 端与 TUI 客户端实时同步历史记录。
- **全局智能去重 (MRU)**：自动清除历史重复指令，重复执行的命令自动提升至顶部（Most Recently Used），保持记录简洁干净。
- **WebDAV 云端自动备份**：支持定时增量备份命令历史至 Nextcloud、Seafile 等 WebDAV 云存储；服务端无本地历史时支持自动从云端恢复。
- **单文件嵌入式部署**：Web 前端静态资源（HTML/JS/CSS/PWA）全量嵌入 Go 二进制文件，无需配置复杂的前端静态文件路径。

### 2. Web 界面 (WebUI)
- **现代化视觉设计**：深海蓝 Dark Glassmorphism（毛玻璃拟态）风格，优雅的 DB9 串口插头图标与 6px 自适应精致滚动条。
- **多串口 Tab 独立终端**：顶部支持多串口 Tab 页签切换，每个串口拥有独立的 `xterm.js` 终端与 `scrollback` 缓冲区，支持后台全时实时接收数据。
- **终端个性化设置**：支持自定义字体（JetBrains Mono、Fira Code、Monaco 等）、字号大小、主题风格（Dark、Light、Blue、Green）及历史回滚行数。
- **可视化历史指令管理器**：提供历史命令的查看、一键填入、在线编辑、删除、导入/导出及 WebDAV 备份管理。
- **智能搜索与剪贴板**：支持终端文本搜索高亮，选中文本自动复制至剪贴板。

### 3. 终端客户端 (`sos-client`)
- **交互式 TUI 界面**：基于 BubbleTea 开发的键盘驱动界面，支持串口选择、波特率、数据位、停止位和校验位配置。
- **当前串口自动高亮**：按下 `Ctrl+T` 唤出串口选择界面时，光标自动高亮定位在当前已连接的串口上。
- **快捷键支持（会话内）**：
  | 快捷键 | 功能描述 |
  |--------|----------|
  | `Ctrl+T` | 打开串口与配置选择面板 |
  | `Ctrl+V` | 打开多行命令编辑与历史选择面板 |
  | `Ctrl+F` | 设置实时输出正则表达式过滤（Grep 模式） |
  | `Ctrl+L` | 开启 / 停止输出日志写入本地文件（支持路径 Tab 补全） |
  | `Ctrl+\` | 切换每行高亮毫秒级时间戳显示 |

- **多行命令编辑器 (`Ctrl+V`)**：
  | 按键 | 功能描述 |
  |------|----------|
  | `Tab` | 在 **命令输入框** 与 **历史搜索列表** 之间切换焦点 |
  | `Alt+Enter` | 立即发送多行命令 |
  | `Ctrl+P` / `Ctrl+N` | 上下导航过滤后的历史指令建议 |
  | `↑` / `↓` 或 `k` / `j` | 浏览历史列表（输入框实时预览完整指令） |
  | `Enter` | 确认选中历史条目并填充至输入框 |
  | `Esc` | 取消并关闭编辑器 |

## 🚀 使用指南

### 1. 启动服务端 (`sos-server`)

#### 命令行直接启动
```bash
# 默认启动（监听 0.0.0.0:2025）
./sos-server

# 指定绑定地址与端口
./sos-server -address 127.0.0.1 -port 8080
```
*配置文件与历史记录会自动保存至 `~/.config/go-serial-over-socket/` 目录。*

#### 使用 Systemd 服务开机自启 (`sos.service`)
1. 将编译好的 `sos-server` 复制到 `/usr/bin/`：
   ```bash
   sudo cp sos-server /usr/bin/sos-server
   ```
2. 将 `sos.service` 复制到 systemd 系统目录：
   ```bash
   sudo cp sos.service /etc/systemd/system/sos.service
   ```
3. 启动并设置开机自启：
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now sos.service
   ```
4. 查看服务运行状态：
   ```bash
   sudo systemctl status sos.service
   ```

---

### 2. 使用 Web 网页端
在浏览器中打开：`http://localhost:2025`（或服务端 IP）

1. **选择串口与连接**：在顶部端口 Tab 栏选择目标串口，在侧边栏配置波特率并点击 **Connect**。
2. **多串口切换**：点击顶部不同串口 Tab 即可切换当前操作终端，所有端口均在后台实时接收并保存数据。
3. **命令历史管理**：点击底部命令栏的 **History** 按钮可管理保存的命令，支持查看、编辑、删除与导入导出。
4. **WebDAV 备份配置**：在 History 面板的 **Sync** 选项卡中配置 WebDAV 服务器地址及凭据。

---

### 3. 使用 TUI 终端客户端 (`sos-client`)
```bash
# 连接到指定服务端
./sos-client -server 127.0.0.1:2025
```
- 进入菜单后使用方向键选择串口，按 `Enter` 快速连接或按 `c` 进入详细串口参数配置。
- 在串口终端会话中：
  - 按 `Ctrl+T` 随时重新唤出串口选择界面（自动高亮当前串口）。
  - 按 `Ctrl+V` 打开多行命令编辑器，按 `Tab` 在输入框与历史列表中切换。
  - 按 `Ctrl+F` 设置实时正则过滤，按 `Ctrl+L` 开启本地日志保存，按 `Ctrl+\` 开启毫秒时间戳。

## ☁️ WebDAV 增量云备份

在 Web 界面的 **Sync** 页面中配置 WebDAV 凭据：

| 配置项 | 描述 |
|--------|------|
| **URL** | WebDAV 服务端地址（如 `https://cloud.example.com/remote.php/dav/files/user/sos/`） |
| **Username** | WebDAV 用户名 |
| **Password** | WebDAV 密码 |
| **Interval (min)** | 自动备份检测间隔（分钟） |
| **Max Backups** | 云端保留的最大备份文件数量 |

备份文件命名格式为 `history_backup_YYYYMMDDHHMMSS.mmm.json`。若服务端首次启动且无本地历史记录，将自动拉取并恢复云端最新的历史备份。

## ⚙️ 命令行参数

### 服务端 (`sos-server`)
```text
-address string   绑定监听地址 (默认 "0.0.0.0")
-port int         绑定监听端口 (默认 2025)
-v                查看版本信息
-h                查看帮助信息
```

### 客户端 (`sos-client`)
```text
-server string    服务端地址 host:port (默认 "127.0.0.1:2025")
-v                查看版本信息
```
